Indexing Strategy

  • products.slug (unique index)
  • products.categoryId + basePrice
  • orders.userId + createdAt
  • orders.orderCode (unique index)
  • flash_sales.status + startTime + endTime

Critical Notes

  • Flash Sale phải dùng Atomic Update.
  • Dùng Cronjob dọn đơn pending.
  • Dùng Idempotency Key cho webhook.
  • MongoDB Replica Set để hỗ trợ Transaction.
